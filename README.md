# LoveTree DTC Site

Mobile-first direct-to-consumer landing page for the connected LoveTree product.

## Current positioning

**Working name:** LoveTree  
**MSRP:** $49.95  
**Primary channel:** TikTok Shop  
**Core message:** A connected ambient light that turns recent moments of peace and love shared online into a living glow.

## Files

- `index.html` — storefront page
- `styles.css` — responsive visual design and animations
- `script.js` — small interaction layer

The site is deliberately static so it can run directly on GitHub Pages or any simple CDN.

## Before launch

1. Replace the placeholder TikTok Shop CTA in `index.html` with the real product URL.
2. Confirm final product/trade name.
3. Add final product photography once hardware is available.
4. Confirm exact box contents and shipping language.
5. Add final privacy, terms, returns, support, and warranty pages.
6. Connect a custom domain if desired.

## GitHub Pages

This repo is intentionally compatible with GitHub Pages. Enable Pages from the repository settings and deploy from the `main` branch root.

## Product note

The page describes the intended LoveTree experience. The live X activity feed, device activation service, WLED firmware, and checkout integration are separate implementation workstreams.
